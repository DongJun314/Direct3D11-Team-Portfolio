## 📜 Project Overview
- **Duration**: `2024.03.18 ~ 2024.05.24`
- **Team Size**: `5 members`
- **Key Contributions**: `Map Tool`, `Inventory System`, `Inventory UI`

<br>

## ⚙️ Development Environment
- **Languages**: `C++`, `HLSL`
- **Tools**: `Visual Studio 2022`
- **Version Control**: `Git`, `GitHub`
- **Rendering API**: `Direct3D 11`

<br>

## ⚒️ Implementations
- **Map Tool**: Implemented various widgets and functions for efficient object placement and editing.
- **Pixel Picking**: Implemented a pixel-picking system that retrieves world coordinates at a constant cost regardless of object count.
- **Inventory System**: Designed as an independent system class, managing items and UI separately from player objects.
